1. 전체 아키텍처 & 개인정보 경계선

민감 원본은 로컬(.gitignore)에 가두고, 검증·비식별된 결과물만 공개 GitHub Pages로 내보냅니다.

2. 하위 시스템별 작동 원리

탭을 전환해 각 엔진의 데이터 처리 흐름과 규칙을 확인하세요 (페이지 내 검색 Ctrl+F 전체 탭 지원)

복수 회계단위 통합과 내부이전 이중계산 방지 원리

노동조합 재정은 중앙 본부(HQ)와 현장 지부(안물 AY · 부평물 BP · 폐지 서물 SS)로 나뉘며, 본부에서 지부로 교부금을 내려보내거나 잔여금을 회수할 때 총액이 부풀려지지 않도록 거래 구분을 엄격히 분리합니다.

3단계 계정과목 체계 (47개 계정)

  • 관(대분류): 수입 3대 관 · 지출 5대 관(운영비, 교섭·투쟁·권익비, 조직·교육비, 조합원복지·연대비, 조정·환급) · 내부이전 · 기초이월
  • 항(중분류) · 목(세부활동): 사업 목적과 구체적 활동을 1:1로 연결하고, 지출형태(식대·인쇄·선물 등 10종)를 보조 축으로 분석합니다.
  • 재원 구분: 통상 활동(일반회계)과 목적 모금(특별모금·찬조)을 분리 집계합니다.

수식·회계 무결성 자동 검증

  • Google Sheets에서 내려받은 ledger.xlsx의 #REF!, #NAME? 등 엑셀 수식 오류를 가장 먼저 차단합니다.
  • 모든 거래는 config/coa.json에 등록된 47개 계정과목과 지출형태 마스터에 정확히 일치해야 통과합니다.
  • 행마다 계산한 누적 잔액과 시트 잔액(unit_bal)을 전수 대조해 본부 1,581,075원 기준 무오류를 보장합니다.

약칭 → 정식 성명 통일 및 2단계 비식별 필터

원장에 뒤섞여 있던 공백, 성 생략 호칭, 직책, 존칭을 title_rules.json 규칙에 따라 내부 데이터에서는 순수 정식 성명만 남기도록 정리하고, 공개 웹으로 나갈 때는 등록된 모든 실명·전화번호·이메일을 완전히 가립니다.

일반 단어 오삭제 방지 장치: 제외 목록(반장, 단장, 전, 신임, 조합원 등)을 무조건 텍스트 전체에서 지우지 않고, 사전에 등록된 실명 앞뒤 경계((?<![가-힣]))와 결합된 경우에만 제거해 신규조합원 간담회, 전년 대비 같은 정상 회계 용어를 안전하게 지킵니다.

조합원 가입 · 탈퇴(3종 사유 · 무증빙 허용) · 재입사 승계 흐름

탈퇴나 지부 이동이 발생해도 기존 조합원 레코드를 삭제하지 않고 불변 ID(M-XXXX)와 이벤트 타임라인(membership_events), 첨부 증빙 목록(member_documents)을 누적해 시점별 재적 인원과 사유 통계를 추적합니다.

가입서 원본 이미지 ↔ 마크다운 1:1 관리

  • _raw/applications/에 원본 사진(JOIN_YYYYMMDD_M-XXXX_성명.jpg)과 요약 마크다운(.md)을 나란히 보관합니다.
  • 상하 반전 촬영본(M-0066 등)은 180° 정방향 회전 후 아카이빙했으며, 주민번호 뒷자리·전화·이메일·생년월일은 Git에서 완전 제외합니다.
  • directory/members.md에서 [열람] 링크를 누르면 기재 원문(노동조합에 바라는 점)과 원본 스캔을 한 번에 대조할 수 있습니다.

탈퇴 사유 · 증빙 유연성 설계

  • 종이 탈퇴서가 없는 현장 실무를 고려해 증빙 0건(구두 메모)부터 다중 첨부(메신저 캡처·인사통보 등 기타)까지 모두 수용합니다.
  • 기간제 조합원이 계약만료·퇴직 후 재입사하면 기존 M-XXXX ID를 그대로 승계해 과거 경조사·근속 이력이 끊기지 않습니다.

SQLite 10-테이블 구조 & 공개 웹 프론트엔드 아키텍처

JSON 사전들을 중첩 없이 평평한 관계형 구조로 설계해 두어, python scripts/manage_members.py export-sqlite 한 줄로 외래키(FK)와 CHECK 제약조건이 검증된 SQLite DB(data/local/accounting.db)를 즉시 생성합니다.

브랜드 컬러 · 테마

물류노조 육각 심볼(#516DB2) + 클라인 블루(#002FA7) 밝은 원장 톤을 기본으로 하며, 상단 버튼(localStorage + <meta name="color-scheme">)으로 다크 모드를 즉시 전환합니다.

반응형 차트 · 탐색 UX

시계열 차트는 한눈에 보기·확대 탐색+미니맵을 모두 지원하며, 모바일에서는 컨테이너 쿼리 기반 3열 수치 요약 카드와 4종 스와이프 탭 덱으로 자동 전환됩니다.

금년 기본 필터 · 딥링크

대시보드·거래 탐색기·아카이브 모두 new Date().getFullYear() 기준 금년을 기본값으로 열고(전체 기간은 맨 뒤 배치), 대시보드 막대를 누르면 거래 탐색기로 필터가 그대로 넘어갑니다.

3. 폴더 및 핵심 파일 지도

공개 추적 파일과 .gitignore 비공개 자산 구분
경로 공개 여부 역할 및 작동 설명
scripts/build_reports.py 공개 추적 ledger.xlsx 파싱, 성명 정규화, 산술·COA 검증, 내부 월간/연간 보고서 및 PNG 차트 생성
scripts/build_site.py 공개 추적 개인정보 마스킹(ledger_public.json) 및 정적 웹(_site/) 53개 HTML 페이지 생성
scripts/validate_site.py 공개 추적 계정/잔액 검산 + 실명·전화·이메일 유출 0건 검사 + 수식 오류·깨진 링크 검사
scripts/people_utils.py 공개 추적 약칭→정식 성명 통일, 존칭·수식어·직책 박리 엔진 및 privacy.json 동기화
scripts/manage_members.py 공개 추적 조합원 가입·탈퇴·재가입·이동 CLI, directory/·_raw/applications/*.md 생성, SQLite 내보내기
scripts/manage_units.py 공개 추적 회계단위(지부) 신설·폐지 관리 및 _raw/{CODE}/ 폴더 자동 생성
web/assets/* 공개 추적 app.css(Option B 토큰·반응형), dashboard.js(Chart.js·미니맵), ledger.js, nav.js
data/public/ledger_public.json 공개 추적 비식별 처리된 509건 공개 원장 스냅샷 (GitHub Actions CI 빌드의 입력 원본)
config/{members,external_people,title_rules,privacy}.json 로컬 전용 조합원 명부(67명)·외부인(5명)·제외/직책 규칙·비식별 금지어(103개) 원본 JSON
directory/*.md & _raw/applications/* 로컬 전용 사람이 바로 열어보는 마크다운 명부, 개별 가입서·탈퇴서 기록 카드 및 원본 스캔
data/latest/ & data/local/accounting.db 로컬 전용 최신 엑셀/CSV/JSON 스냅샷 및 SQLite 10-테이블 관계형 로컬 DB

4. 상황별 실무 운영 명령어

클릭해 각 상황별 실행 명령을 펼쳐 확인하세요.
월간 회계 마감 후 보고서 · 공개 웹 동시 갱신 
# 1. Google Sheets에서 data/latest/ledger.xlsx 갱신 후 내부 검증 및 보고서 생성
python scripts/build_reports.py --month 2026-09 --year 2026

# 2. 공개 웹용 데이터 재비식별 + _site/ 빌드 + 개인정보·링크 검증
python scripts/build_site.py
python scripts/validate_site.py
조합원 가입 · 무증빙/다중증빙 탈퇴 · 계약만료 후 재입사 처리 
# 현직 요약 및 변동 이력 확인
python scripts/manage_members.py summary
python scripts/manage_members.py history --limit 20

# 신규 가입 (동일 성명+생년월일 비현역자 존재 시 자동으로 재가입·ID 승계 처리)
python scripts/manage_members.py join --name 홍길동 --birth 950101 --unit BP --shift 야근 --emp-type 기간제 --doc "가입서=파일.jpg"

# 탈퇴 처리 (사유 3종: 정년퇴직 / 계약만료·퇴직 / 기타 · 무증빙 가능)
python scripts/manage_members.py withdraw --name 홍길동 --category 계약만료·퇴직 --reason "계약 종료" --doc-note "구두 확인"
마크다운 사전 · SQLite DB 동기화 및 지부 신설/폐지 
# directory/*.md 및 _raw/applications/*.md 일괄 재생성
python scripts/manage_members.py export-md

# SQLite 로컬 DB (data/local/accounting.db) 생성/동기화
python scripts/manage_members.py export-sqlite

# 회계단위(지부) 목록 확인
python scripts/manage_units.py list
